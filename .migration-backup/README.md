# LeadForge — Your Personal Money Machine

Mobile-first autonomous revenue workspace. Finds leads, writes emails, sends them, creates payment links, and collects money — all from your phone. Deploy once, runs forever.

---

## How it works (and how you make money)

LeadForge is a full business operations tool you control. Here's the exact money flow:

### 1. Find a lead
Use Chat: type `find web design leads in Lagos` or `find 5 e-commerce businesses in London` — AI generates real prospects with names, companies, emails, and titles.

### 2. Send outreach
Type `draft outreach email for [lead name] offering website redesign at $1500`. The AI writes the email. Type `send it` and it fires from your connected email account automatically.

### 3. Close the deal
Track everything in the Deals pipeline. Move deals from Lead → Discovery → Proposal → Won.

### 4. Get paid
Type `create payment request for [client name] $1500 for website project`. A Flutterwave payment link is generated and emailed to the client. When they pay, you get a webhook → receipt auto-emailed to client → deal marked Won.

### 5. Deliver
Track the project milestones in Delivery so the client can see progress.

**You keep 100% of every payment. LeadForge takes nothing.**

## Deploy to Render — step by step

### Step 1: Render account
Go to [render.com](https://render.com) → sign up free

### Step 2: New Web Service
- **New +** → **Web Service**
- Connect GitHub → pick `daviddan-241/launchpad-ai-platform`
- Render sees the `Dockerfile` automatically

### Step 3: Set environment variables
In Render → your service → **Environment tab**:

| Variable | Value | Notes |
|---|---|---|
| `APP_URL` | `https://your-name.onrender.com` | Your Render URL — set AFTER deploy |
| `GEMINI_API_KEY` | your key | [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey) — **free** |
| `GROQ_API_KEY` | your key | [console.groq.com](https://console.groq.com) — **free** |
| `SESSION_SECRET` | *(click Generate)* | Render auto-generates |
| `APP_ENCRYPTION_KEY` | *(click Generate)* | Render auto-generates |
| `SCHEDULER_SECRET` | *(click Generate)* | Render auto-generates |

> **SESSION_SECRET and APP_ENCRYPTION_KEY are also auto-generated by the app on first boot** if you don't set them. So even if you skip them, it still works — the app writes `secrets.json` to the mounted disk and reuses them forever.

### Step 4: Deploy
Click **Create Web Service**. ~5 minutes to build. 

Your live URL: `https://your-name.onrender.com`

Go there → **Sign up** → you're in.

### Step 5: Set APP_URL
After deploy, copy your `.onrender.com` URL, go back to Environment → set `APP_URL` → hit **Save** → Render restarts automatically.

## Set up email (to actually send)

1. Open app → **Settings** → **Email**
2. Add SMTP credentials:
   - **Gmail**: your Gmail + [App Password](https://myaccount.google.com/apppasswords) (enable 2FA first, then generate app password)
   - **Any email host**: SMTP host, port (usually 587), username, password
3. Save → you can now send real outreach from Chat

---

## Set up Flutterwave (to collect payments)

1. Create account at [flutterwave.com](https://flutterwave.com)
2. Dashboard → Settings → API Keys → copy **Secret Key**
3. Add to Render: `FLUTTERWAVE_SECRET_KEY` = your key
4. In Flutterwave dashboard → Webhooks → set URL: `https://your-name.onrender.com/api/payments/webhook`
5. Set a webhook hash → add as `FLUTTERWAVE_WEBHOOK_HASH` in Render

## UptimeRobot — keep app alive 24/7 (free)

Render's free tier sleeps after 15 min. UptimeRobot + the app's built-in self-ping prevent this.

1. Go to [uptimerobot.com](https://uptimerobot.com) → free account → **Add Monitor**
2. Type: **HTTP(s)** | Interval: **5 minutes**
3. URL: `https://your-name.onrender.com/api/ping`
4. **Create Monitor** — done

The app also self-pings every 14 minutes as backup. Together they guarantee 24/7 uptime.

## Architecture

- **Next.js 16** — App Router, standalone Docker output
- **File-based JSON** at `DATA_DIR/app-data.json` (Render 1GB disk)  
- **No database needed** — no Redis, no Postgres, no external services
- **Auto-generated secrets** — written to `DATA_DIR/secrets.json` on first boot
- **AI**: Gemini → Groq → Ollama fallback
- **One Docker container** — everything runs in it
